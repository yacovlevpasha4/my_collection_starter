# 🎬📚🎮 Моя коллекция - Стартовый набор

Привет! Это твой стартовый набор для создания личного каталога (на выбор темы: фильм, книг или игр).

## ✅ Что уже готово:
- `styles.css` - CSS-каркас с готовыми классами (.card, .grid, .btn)
- `base.html` - общий скелет сайта (хедер с меню, футер)
- `collection.db` - пустая база данных (SQLite)
- `requirements.txt` - список зависимостей (Flask)

## 🎯 Что тебе нужно сделать (в течение курса):
1. **Настроить тему** - выбери цвета в `styles.css` (кино/книги/игры)
2. **Сверстать страницы** - заполнить HTML-файлы в папке `templates/` - («Оживить» шаблоны — вставить в готовые HTML-файлы (в папке templates/) теги шаблонизатора Jinja2 ({% for %}, {{ item.title }}), чтобы данные из Python красиво выводились в карточках на сайте.)
3. **Написать Python-код** - дописать роуты и запросы к БД в `app.py`
4. **Добавить JS-интерактив** - написать фильтры и поиск в `script.js`
5. **Наполнить базу** - добавить 5-10 элементов через форму на сайте

## 🚀 Как запустить проект:
```bash
# 1. Установи Flask (один раз)
python -m pip install -r requirements.txt

# 2. Создай базу данных СТРОГО перед запуском (один раз)
python init_db.py

# 3. Запусти сервер
python app.py

# 3. Открой в браузере
http://127.0.0.1:5000
